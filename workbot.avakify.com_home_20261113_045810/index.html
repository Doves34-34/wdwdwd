Before you decide

Do I need two game accounts?

No. Pair one account you own with a helper account supplied by Avakn Bot, or attach two accounts you own.

Will my slot start by itself?

Only if you turn on auto-run for that slot. Manual start is the default, and starting one run does not turn auto-run on.

What happens at renewal?

Renewal keeps the same Duo slot, accounts and settings. Wallet credit is used first, then a saved card if more is needed.

Can I switch which account works?

Yes. Swap the worker and customer roles on the slot page when the slot allows it. You keep the same slot.

What if a run stops?

The dashboard shows why. With auto-run on, the slot tries to start again; otherwise press Start when you are ready.

Do I pay to sign up?

No. You pay only when you reserve a slot.
